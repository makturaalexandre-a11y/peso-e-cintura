# Peso e Cintura

App pessoal para registrar peso e circunferência da cintura toda semana. Calcula IMC, faixa de IMC (OMS), quilos até a faixa saudável e cintura desejada (IDF/OMS e razão cintura/altura < 0,5). Mostra gráficos de evolução e o comparativo com a semana anterior.

- Funciona offline e pode ser instalado no celular (PWA).
- Os dados ficam só no aparelho (localStorage). Use **Exportar backup** de vez em quando.

## Instalar no celular
- **Android (Chrome):** abra o endereço do app → menu ⋮ → **Instalar app** (ou "Adicionar à tela inicial").
- **iPhone (Safari):** abra o endereço → botão Compartilhar → **Adicionar à Tela de Início**.

Estimativas gerais para adultos; não substitui avaliação médica.
